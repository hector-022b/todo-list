# Todo List

A simple Todo List application built with React and Vite as part of the Code the Dream React curriculum. This project will be expanded throughout the course as new React concepts and features are introduced.

## Features

- Displays a list of todos
- Built with React
- Uses Vite for fast development

## Installation

1. Clone the repository:

```bash
git clone https://github.com/hector-022b/todo-list.git
```

2. Navigate to the project folder:

```bash
cd todo-list
```

3. Install the project dependencies:

```bash
npm install
```

## Running the Development Server

Start the Vite development server with:

```bash
npm run dev
```

Then open the local URL shown in the terminal (usually `http://localhost:5173` or another available port).
